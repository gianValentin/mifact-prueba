# MifactPrueba

El proyecto frontend fue generado con [Angular CLI](https://github.com/angular/angular-cli) version 18.2.21.

Corre `npm start --prefix ./mifactPruebaFront` para un servidor de desarrollo. navega a `http://localhost:4200/`.


El proyecto backend fue generado con [Spring-Boot 4](https://github.com/spring-projects/spring-boot) version 4.0.8 y [Java 17](https://github.com/openjdk/jdk17).

Corre `./mifactPrueba/mvnw spring-boot:run -f ./mifactPrueba/pom.xml` para un servidor de desarrollo. navega a `http://localhost:8090/`.
